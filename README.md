## 故事背景

【相傳二戰期間，美軍轟炸萬丹地區，幸得萬丹萬惠宮媽祖顯靈，接下炸彈或踢走炸彈，守護鄉親平安，萬丹始能幸免於難】

## 玩法

- **操作：** 手機以手指滑動、電腦以滑鼠拖曳，像切水果一樣撥開炸彈。
- **向上或向左右撥開炸彈：** 加分。
- **向下撥或讓炸彈落地：** 扣分。
- **護身符：** 落地可加分。
- **時間：** 共 60 秒，起始分數 100 分，分數歸零即提前失敗；30 秒後難度提升。
- **結算：** 依分數給予星級評價；存活到最後，天空放晴、村民歡呼。

### 連擊

連續成功撥開炸彈會累積連擊倍率，分數加成更高。

## 特色

- 純 HTML5 Canvas 製作，**單一 `index.html`**，無需安裝、無外部依賴。
- 手機直向優先，支援觸控與滑鼠，桌機也能玩。
- 全程程式繪製的像素風美術（廟宇、三合院、媽祖、村民等）。
- 以 Web Audio API 即時合成音效與背景音樂，無外部音檔。
- 內建暫停與靜音按鈕。
